## 📦 Что в релизе

| Файл | Что это | Кому |
|---|---|---|
| `Kitsune-Browser-Setup-{{VERSION}}-x64.exe` | Установщик для 64-битной Windows | **Большинству пользователей** |
| `Kitsune-Browser-Setup-{{VERSION}}-ia32.exe` | Установщик для 32-битной Windows | Старые ПК и 32-битные системы |
| `Kitsune-Browser-Portable-{{VERSION}}-x64.exe` | Portable-версия, без установки | Флешка, «не трогать систему» |
| `Kitsune-Browser-Portable-{{VERSION}}-ia32.exe` | Portable для 32-битной Windows | То же, для 32-бит |
| `latest.yml` / `win32.yml` | Файлы каналов автообновления | Служебное (x64 / ia32) |
| `*.blockmap` | Данные для дифференциальных обновлений | Служебное |
| `SHA256SUMS.txt` | Контрольные суммы SHA-256 | Проверка целостности |
| `build-info.json` | Машинный манифест сборки | Служебное |

Установщик создаёт **ярлык на рабочем столе** и в меню «Пуск», регистрирует
браузер в системе («Приложения по умолчанию» — Kitsune можно назначить
основным) и добавляет запись в «Установка и удаление программ».
Удаляется штатно, профиль с историей и паролями при удалении сохраняется.

## 🚀 Установка

1. Скачайте `Kitsune-Browser-Setup-{{VERSION}}-x64.exe` (или `-ia32` для
   32-битной системы).
2. Запустите файл. Windows покажет предупреждение SmartScreen — сборка не
   подписана платным сертификатом: **«Подробнее» → «Выполнить в любом случае»**.
3. Установщик ставит браузер только для текущего пользователя (права
   администратора не нужны), каталог можно изменить.
4. После установки ярлык появится на рабочем столе, браузер запустится сам.

Тихая установка: `Kitsune-Browser-Setup-{{VERSION}}-x64.exe /S`.

## 🔄 Автообновление

Начиная с этой версии браузер сам проверяет релизы на GitHub:

* проверка при запуске (через 12 секунд, чтобы не мешать старту) и раз в 6 часов;
* новая версия скачивается в фоне, внизу окна появляется полоса с прогрессом;
* установка — по кнопке «Перезапустить и обновить» (или из меню, или со страницы
  `kitsune://settings`); можно отложить — обновление поставится при выходе;
* контроль: `SHA-512` установщика из `latest.yml` проверяется до запуска;
* выключить автопроверку можно в настройках.

Две архитектуры обновляются независимо: 64-битная сборка берёт `latest.yml`,
32-битная — `win32.yml`, поэтому 32-битный браузер никогда не скачает
64-битный установщик.

## ✨ Возможности

**Интеграция с Windows**
* Kitsune регистрируется как браузер для `http`, `https`, `.htm` и `.html`.
* На странице настроек показывается текущий статус браузера по умолчанию.
* Кнопка открывает штатное окно Windows, где пользователь подтверждает выбор.
* Ссылки, открытые из других приложений, передаются уже запущенному Kitsune,
  а не теряются во втором экземпляре.

**Блокировка рекламы (уровень uBlock Origin)**
* Сетевая блокировка через `webRequest` — запрос не уходит в сеть.
* Синтаксис ABP/uBO: `||домен^`, `/regex/`, `@@`-исключения, опции
  `$script`, `$image`, `$third-party`, `$domain=`, `$important`, `$popup`,
  `$redirect` (подмена рекламного скрипта пустышкой), `$removeparam`
  (чистка UTM-меток), `$generichide`.
* Косметические правила `##`, `#@#`, `#?#` и процедурные `:has-text()`.
* **Пипетка элементов**: «Заблокировать элемент» из меню или правого клика.
* Свои правила и белый список сайтов, сохраняются между запусками.
* Кнопка загрузки EasyList + EasyPrivacy + Cookie (≈100 000 правил).
* Статистика: топ заблокированных доменов и лента запросов на `kitsune://blocked`,
  счётчик на каждой вкладке.

**Приватность**
* DuckDuckGo по умолчанию (обычный / Lite / HTML без JavaScript).
* Безопасный поиск: выключен / умеренный / строгий.
* Никакой телеметрии; User-Agent без метки `Electron` — сайты видят обычный
  Chromium 152; заголовок `DNT: 1`.

**Менеджер паролей**
* Диалог «Сохранить пароль?», автозаполнение форм входа (в том числе на
  React/Vue-сайтах).
* Шифрование средствами ОС (DPAPI в Windows), страница `kitsune://passwords`
  со списком входов, показом пароля по требованию и удалением.

**Интерфейс**
* Вкладки с перетаскиванием, дублированием, закрытием остальных/справа,
  восстановлением сессии, счётчиком блокировок.
* Недавно закрытые вкладки (`Ctrl+Shift+T`), закладки, история, поиск на
  странице, масштаб, тёмная тема с лисьим акцентом.
* Горячие клавиши работают, даже когда фокус внутри страницы.
* Нативное меню-«гамбургер» и полоса обновления внизу окна.

## ⚠️ Известные ограничения

* Установщики не подписаны — SmartScreen предупредит при первом запуске.
* 32-битная сборка использует Electron 43: в Electron 44 больше нет бинарников
  `win32-ia32`. Возможности сборок идентичны.
* Portable-версия не обновляет себя автоматически — её заменяют вручную.
* Автообновление работает только в установленной сборке под Windows.
