# Kitsune Browser Android 1.6.1

Отдельная Android-версия Kitsune Browser. Windows/Electron-проект находится в
корне репозитория и не изменяется Android-сборкой.

## Возможности

- WebView-браузер с адресной строкой и поиском DuckDuckGo;
- назад, вперёд, обновление и несколько вкладок;
- создание, переключение и закрытие вкладок;
- базовый встроенный список рекламных хостов;
- тёмная панель управления и User-Agent `Kitsune/1.6.1`.

## Сборка

```powershell
cd C:\Users\Hoshino\Documents\brow\android
.\gradlew.bat assembleDebug
```

Устанавливаемый тестовый APK будет создан в `app/build/outputs/apk/debug/`.
На локальной машине сборка требует Android SDK 35 и JDK 17. В CI это
устанавливается workflow `.github/workflows/android-release.yml`.

В Android WebView нет полного аналога Chromium partition-сессий Electron,
поэтому 1.6.1 не заявляет полноценный приватный режим с гарантированной
изоляцией cookies и Web Storage. Это будет отдельной задачей Android-версии.

## GitHub Release v1.6.1

Workflow Android Release публикует подписанный APK по тегу `v1.6.1`.
Первая публикация использует одноразовый CI-ключ, поэтому для следующих
обновлений нужно настроить постоянный keystore с alias `kitsune` и заменить
шаг подписи в workflow. APK из первой публикации устанавливается, но его
нельзя использовать как основу для обновления после смены ключа.

Это первая базовая Android-реализация, а не перенос всех возможностей Windows.
Пока отсутствуют загрузки файлов, менеджер паролей, настройки, закладки,
полная ABP/uBO-фильтрация и изолированный приватный режим. HTTP без TLS
отключён. Проверка на реальном устройстве необходима перед публичным релизом.
