# 🦊 Kitsune Browser

**Быстрый. Тихий. Без рекламы.**

Kitsune Browser — настольный браузер на Electron с настоящей сетевой блокировкой рекламы
(движок совместим с правилами Adblock Plus и uBlock Origin) и приватным поиском
**DuckDuckGo** по умолчанию. Никакой телеметрии, никаких облачных сервисов,
никаких аккаунтов. В рантайме — единственная внешняя зависимость:
`electron-updater` для автообновления.

**Скачать:** [последний релиз](https://github.com/akihoshinonyx/Kitsune-Browser/releases) ·
**Документация:** [описание проекта](docs/DESCRIPTION.md) ·
[установка, сборка, обновление](docs/INSTALL.md)

## Установка

| Система | Файл из релиза |
|---|---|
| Windows 10/11, 64-битная | `Kitsune-Browser-Setup-1.7.2-x64.exe` |
| Windows 10, 32-битная | `Kitsune-Browser-Setup-1.7.2-ia32.exe` |
| Без установки (флешка) | `Kitsune-Browser-Portable-1.7.2-<арх>.exe` |

```powershell
# обычная установка: мастер, ярлык на рабочем столе, меню «Пуск», запись в «Установка и удаление программ»
.\Kitsune-Browser-Setup-1.6.0-x64.exe

# тихая установка для скриптов
.\Kitsune-Browser-Setup-1.6.0-x64.exe /S

# установка скриптом из собранной папки (без установщика)
powershell -ExecutionPolicy Bypass -File .\tools\install.ps1 -Run

# удаление
powershell -ExecutionPolicy Bypass -File .\tools\install.ps1 -Uninstall
```

* Установка **только для текущего пользователя** — права администратора не нужны,
  каталог можно выбрать. Скрипт `tools/install.ps1` умеет и `-Machine` (для всех
  пользователей), `-NoDesktopShortcut`, `-Uninstall`.
* Установщик **создаёт ярлык на рабочем столе** и в меню «Пуск», а также
  регистрирует браузер в системе: Kitsune появляется в
  «Параметры → Приложения → Приложения по умолчанию» и его можно назначить
  основным браузером.
* ⚠️ Сборки не подписаны сертификатом code signing, поэтому SmartScreen покажет
  «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
  Целостность проверяется по `SHA256SUMS.txt`.
* 32-битная сборка использует Electron 43 — в Electron 44 бинарников
  `win32-ia32` больше нет. Возможности сборок одинаковые, профиль общий.

## Автообновление

* Браузер сам проверяет релизы на GitHub: при запуске (через 12 с) и раз в 6 часов.
* Новая версия скачивается в фоне, внизу окна появляется полоса с прогрессом;
  установка — по кнопке «Перезапустить и обновить», из меню или со страницы
  `kitsune://settings`; можно отложить — обновится при выходе.
* Перед запуском установщика проверяется его `SHA-512` из `latest.yml`.
* **Два канала:** 64-битная сборка берёт `latest.yml`, 32-битная — `win32.yml`.
  Иначе 32-битный браузер скачал бы 64-битный установщик.
* Portable-сборка не обновляет себя — браузер об этом честно сообщит.
* Проверку можно отключить в настройках.

## Возможности

| Возможность | Описание |
|---|---|
| 🛡 **Блокировка рекламы уровня uBlock Origin** | Сетевая блокировка через `webRequest` + косметические правила (реклама скрывается на странице) + `$redirect` (рекламный скрипт подменяется пустышкой) + `$removeparam` (чистка utm-меток) + `$popup` |
| 🎯 **Пипетка элементов** | «Заблокировать элемент» из меню или правого клика по странице — как в uBlock Origin |
| 📃 **Свои правила** | Синтаксис ABP/uBO: `||домен^`, `##.banner`, `example.com##.ad:has-text(Реклама)`; правила сохраняются между запусками |
| 🗝 **Менеджер паролей** | Диалог «Сохранить пароль?», автозаполнение форм входа, шифрование средствами ОС (DPAPI/Keychain), страница `kitsune://passwords` |
| 🤍 **Белый список сайтов** | Блокировку можно выключить для одного сайта — если он ломается; список сохраняется |
| ⬇ **Загрузка больших списков** | Кнопка на `kitsune://blocked` скачивает EasyList + EasyPrivacy + Cookie (≈100 000 правил) |
| 🔍 **DuckDuckGo по умолчанию** | Три режима: обычный, Lite и HTML-версия без JavaScript |
| 🔒 **Безопасный поиск** | Режимы «выключен / умеренный / строгий» (`kp=-2 / -1 / 1`) |
| 🗂 **Вкладки** | Перетаскивание с подсветкой цели, дублирование, восстановление сессии, счётчик блокировок на каждой вкладке |
| 🖱 **Контекстное меню страницы и вкладки** | Правый клик по странице: копировать, открыть ссылку в новой вкладке, проверить элемент, заблокировать домен |
| ↩ **Недавно закрытые** | Стек из 25 адресов в main-процессе, `Ctrl+Shift+T` возвращает вкладку |
| ⌨ **Хоткеи из любого места** | Комбинации перехватываются через `before-input-event`, поэтому работают и когда фокус внутри страницы |
| 🔍 **Масштаб страницы** | `Ctrl + «+» / «−» / 0` с бейджем процентов в тулбаре |
| ⭐ **Закладки и история** | Локальные JSON-файлы, боковая панель, поиск, удаление |
| 🔎 **Поиск на странице** | `Ctrl+F` с подсветкой совпадений и счётчиком |
| 🚫 **Блокировка всплывающих окон** | Popup открывается как новая вкладка, а не новым окном; рекламные сети гасятся по `$popup` |
| 📊 **Статистика блокировок** | Топ заблокированных доменов и лента последних запросов на `kitsune://blocked` |
| ⚡ **Оптимизированный UI** | Склейка IPC-событий, кэш решений блокировщика, переиспользование DOM-узлов вкладок — YouTube и соцсети не «залипают» |
| 🖥 **Свой интерфейс** | Полоса вкладок, адресная строка с подсказками (native-меню, не HTML — иначе оно оказывается под вкладкой), тёмная тема с лисьим акцентом |

## Быстрый старт

```powershell
npm install      # electron + electron-builder (dev) + electron-updater (runtime)
npm run icon     # генерирует build/icon.png и build/icon.ico (без внешних зависимостей)
npm start        # запускает браузер
```

## Движок

| Компонент | Версия |
|---|---|
| Electron | 44.4.5 |
| Chromium | 152.0.7977.130 |
| Node.js | 24.x (встроенный в Electron) |

**User-Agent.** Electron по умолчанию дописывает в строку `Electron/44.4.5` и имя приложения —
часть сайтов (Google, Netflix, банки, видеосервисы) считает такой браузер встроенным движком и
отдаёт упрощённую или сломанную страницу. Kitsune собирает UA сам (`buildUserAgent()` в
`src/main/main.js`): сообщает настоящую версию Chromium из `process.versions.chrome` и ставит
метку `Kitsune/1.7.2` в конец строки — так же, как это делают Edge и Opera.

## Внутренние страницы

| Адрес | Назначение |
|---|---|
| `kitsune://home` (или `kitsune://newtab`) | Стартовая страница с поиском и быстрыми ссылками |
| `kitsune://settings` | Настройки: поисковик, безопасный поиск, блокировщик, пароли, домашняя страница |
| `kitsune://blocked` | Статистика блокировки, свои правила, белый список сайтов, загрузка EasyList/EasyPrivacy |
| `kitsune://passwords` | Менеджер паролей: сохранённые входы, показ/копирование, автозаполнение |
| `kitsune://about` | Версии Electron/Chromium/Node, путь к папке фильтров |

В разделе «Данные» на `kitsune://settings` можно экспортировать закладки в HTML
Netscape и историю в JSON, а также импортировать их обратно. Импорт добавляет
только новые HTTP/HTTPS-записи и перед изменением профиля создаёт резервную копию
`history.json` или `bookmarks.json` с суффиксом `.backup-<время>`.

## Как работает блокировка рекламы

1. Каждая вкладка — это `WebContentsView` на общей сессии `persist:kitsune`.
2. Для сессии подписан обработчик `onBeforeRequest`, который спрашивает движок
   `AdBlocker.getAction(...)`. Кроме «блокировать/пропустить» движок умеет
   **подменять ответ** (`$redirect`) и **чистить адрес** (`$removeparam`).
3. Движок (`src/main/adblock.js`) разбирает правила формата Adblock Plus / uBlock Origin:

```
||ads.example.com^          # домен и все поддомены
/banner/*.gif               # шаблон с *
@@||good.example.com^       # исключение (белый список)
||tracker.io^$script        # только скрипты
||metrics.net^$~image       # всё, кроме картинок
||ads.example.com^$third-party
||cdn.site.com^$domain=site.com
||forced.net^$important     # игнорирует исключения
||ads.test/adsbygoogle.js$script,redirect=noopjs   # скрипт → пустышка
$document,removeparam=utm_source                   # чистка меток у ссылок
||popads.net^$popup         # гасит всплывающее окно
##.ad-banner                # скрыть элемент (косметика)
example.com##.promo         # скрыть только на example.com
example.com#@#.promo        # исключение из скрытия
site.ru##div:has-text(Реклама)   # процедурное правило (поиск по тексту)
@@||site.ru^$generichide    # отключить общую косметику на сайте
! комментарий
```

4. Для скорости «чисто доменные» правила лежат в `Map` и проверяются по суффиксам хоста;
   регулярные выражения строятся только если в шаблоне есть `*` или `^`.
   Разбор URL и решения по запросам кэшируются — на тяжёлых сайтах это экономит CPU.
5. Косметические правила применяются к странице через `insertCSS` (по одному селектору,
   чтобы ошибка в одном правиле не ломала остальные); процедурные (`:has-text`) —
   небольшим скриптом с `MutationObserver`.
6. Счётчики по вкладкам и доменам накапливаются в `AdBlocker` и показываются в UI.

### Свои правила и списки

- **Свои правила** добавляются на `kitsune://blocked` или пипеткой («Заблокировать
  элемент на странице» в меню). Они хранятся в
  `%APPDATA%\Kitsune Browser\adblock-user.txt` и переживают перезапуск.
- **Белый список сайтов** («Отключить блокировку на этом сайте») хранится в
  `adblock-whitelist.json`.
- **Большие списки** (EasyList, EasyPrivacy, EasyList Cookie) скачиваются кнопкой
  «Скачать списки» на `kitsune://blocked` в папку userData:

```
%APPDATA%\Kitsune Browser\easylist.txt
```

Файлы `*.txt` из `userData` и из папки фильтров (путь виден на `kitsune://about`)
подхватываются при следующем запуске. Файл `src/main/filters/extra-example.txt` —
это пример формата; он намеренно **не** загружается автоматически, переименуйте его,
если хотите включить.

## Безопасность

* `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true` во всех вкладках.
* Renderer видит только белый список методов через `contextBridge` — без доступа к `require`.
* **Полный API браузера (`window.kitsune`) доступен только внутренним страницам.**
  Обычный сайт не может прочитать историю, закладки или пароли — ему отдаётся лишь
  узкий мост `window.kitsunePage` для автозаполнения и пикера элементов.
* Все приватные IPC-каналы проверяют отправителя (`src/main/ipc-guards.js`):
  запрос пароля принимается только от того домена, к которому он относится.
* Пароли шифруются средствами ОС через `safeStorage` (DPAPI в Windows) и никогда
  не отдаются интерфейсу в открытом виде без явного запроса.
* Внутренние страницы закрыты CSP (`default-src 'self'`).
* `fullscreen` и запись в буфер разрешаются безопасно, а геолокация, микрофон и вебкамера требуют явного выбора пользователя; постоянные разрешения можно отозвать в настройках.
* `DNT: 1` отправляется в каждом запросе.

| `%APPDATA%\Kitsune Browser\adblock-whitelist.json` | Сайты с выключенной блокировкой |
| `%APPDATA%\Kitsune Browser\filters\*.txt` | Ваши дополнительные списки фильтров |
